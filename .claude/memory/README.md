# ذاكرة مشروع Kareem Pro

هذا المجلد هو **المصدر الوحيد للحقيقة** لسياق المشروع وقواعد العمل فيه.

## لماذا داخل المستودع

كريم يعمل على المشروع من أكثر من جهاز. ذاكرة تطبيق Claude محلية لكل جهاز ولا
تنتقل، فكانت كل جلسة على جهاز جديد تبدأ من الصفر. وضع الذاكرة هنا — ومتتبَّعة في
Git — يجعلها تصل لأي جهاز بأمر `git pull` واحد.

## القواعد

1. **أول أي جلسة**: `git pull` ثم قراءة `MEMORY.md` كاملًا قبل أي عمل.
2. **أي قرار أو قاعدة أو عطل جديد** يُكتب هنا **ويُعمل له Commit في نفس الجلسة**.
   قرار غير مكتوب = قرار ضائع على الجهاز الآخر.
3. **عند التعارض**: الحالة الفعلية للملفات وGit تسبق أي شيء مكتوب هنا. وما هنا
   يسبق `AGENTS.md` و`AI_HANDOFF.md` و`AI_START_PROMPT.md` (ملفات متقادمة —
   انظر `07-outdated-files.md`).
4. **ممنوع منعًا باتًا** كتابة أي مفتاح أو توكن أو كلمة مرور أو بيانات عميل أو
   أرقام هواتف شخصية في أي ملف هنا. **أسماء** متغيرات البيئة فقط، بلا قيمها.
5. الملفات مرقّمة بالأولوية. لا تُحذف ملفات — تُحدَّث.
